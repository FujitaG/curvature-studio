# Changelog

## 0.1.0 — 2026-10-15

Initial release.

- Interactive 2D and 3D graph editing, Bond/Brace structural roles, and side-by-side comparison.
- Effective and Ollivier–Ricci curvature for finite, undirected, unit-weight graphs.
- Results tables, CSV/JSON downloads, and SVG/PNG figure export.
- Reproducible polyhedron templates generated from geometric constructions.
- Local project storage, file import/export, and recovery controls.
- Independent mathematical references, analytic examples, browser tests and CI.

See [mathematical validation](docs/math-validation.md) for the supported model,
verification methods and numerical limitations.
